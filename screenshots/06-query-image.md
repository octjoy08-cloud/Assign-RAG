# Query Endpoint - Image-Based Retrieval

## Endpoint: POST /query with image filtering

### Description
Query for image-based content and their AI-generated descriptions. Images in PDFs are automatically processed with GPT-4o-mini to generate detailed descriptions that are then embedded and searchable.

### Request

```bash
curl -X POST "http://localhost:8002/query?q=charging%20connector%20diagram&chunk_types=image"
```

### Response - Image Query Result

For documents containing diagrams and visual content, the system returns:

```json
{
  "answer": "Image-based information retrieved successfully",
  "sources": [
    {
      "content": "[Image description generated by vision model: Shows a detailed diagram of EV charging connectors including SAE J1772 Level 1/2, CCS, and CHAdeMO connectors with labeled components and pin assignments. The diagram displays connector safety features and grounding mechanisms.]",
      "type": "image",
      "page": 3,
      "score": 0.8923456789012345
    },
    {
      "content": "[Image description: Illustration of Level 2 charging station installation diagram with electrical wiring schematic, circuit breaker placement, and wall-mounted charger setup guidelines for residential use.]",
      "type": "image",
      "page": 2,
      "score": 0.7654321098765432
    }
  ],
  "total_sources": 2,
  "query": "charging connector diagram",
  "filter_types": ["image"]
}
```

### Multimodal Vision Processing

#### Automatic Image Analysis

The system automatically:
1. **Extracts** images from PDF documents
2. **Analyzes** images using GPT-4o-mini vision model
3. **Generates** descriptive text summaries
4. **Embeds** descriptions for semantic search
5. **Indexes** searchable image content

#### Image Features Captured

- Diagrams and schematics
- Charts and graphs
- Photographs and illustrations
- Icons and visual indicators
- Technical drawings
- UI screenshots

### Image Query Use Cases

**Finding Visual Diagrams**
```
"Show me the charging setup diagram"
"Find the battery component layout diagram"
"What does the dashboard warning symbol look like?"
```

**Visual Specifications**
```
"What are the charging connector types?"
"Show me different EV models"
"Display the electrical wiring diagram"
```

**Locating Instructions**
```
"How to connect the charging cable?"
"Where is the charging door located?"
"What does the LED indicator mean?"
```

### Configuration

Control image processing via environment variables:

```bash
# Enable vision model (default: true)
PROCESS_IMAGES=true

# Requires valid OpenAI API key for GPT-4o-mini
OPENAI_API_KEY=sk-...
```

### Benefits of Multimodal RAG

✓ **Complete Understanding**: Combines text explanations with visual information
✓ **Better UX**: Users can find diagrams without knowing technical terms
✓ **Accuracy**: Vision descriptions prevent misinterpretation of complex diagrams
✓ **Accessibility**: Makes visual content text-searchable for accessibility tools
✓ **Comprehensive Search**: Single query searches across all content types

### Note on Image Processing

- Requires valid OPENAI_API_KEY
- Images are processed asynchronously during ingestion
- Fallback text is provided if vision model fails
- Image processing can be disabled via PROCESS_IMAGES=false

### Response Fields

| Field | Type | Description |
|-------|------|-------------|
| `content` | string | AI-generated image description |
| `type` | string | Always "image" for image results |
| `page` | integer | Source page number |
| `score` | float | Relevance score for the description |
